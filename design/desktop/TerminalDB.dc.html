The ledger block is the atomic unit — everything (search, AI, runbooks, export) operates on it.

PERMISSION / RISK SYSTEM
CLASSEXAMPLESBEHAVIOR
● read-onlyls, cat, git status, kubectl getRun once / allow similar this session
▲ writedocker push, kubectl apply, npm publishAlways asks · shows target + blast radius
▲ destructiverm -rf, DROP TABLE, terraform destroy, sudo, secretsAsks + explicit checkbox, never "allow similar"

? unknownunrecognized binaries, curl | shTreated as destructive until classified
Invariants: the AI can only propose; execution requires a human gesture. Take Over / Stop is always visible while an agent acts. Every approval is recorded on the block. Risk can be raised by rules, never lowered below the derived class.
